# Bounded checks and repeatability

Chapter 5 connects the measurement results to possible uses and limitations. Several checks have deliberately narrow interpretations.

| Check | What it can address | What it does not establish |
|---|---|---|
| Repeat-generation comparison | Sensitivity to repeated measurements for the selected models and evidence | General stability for every model, country or future version |
| Review-trigger illustration | Behaviour of a specified rule and penalty schedule on the chosen sample | Realised operational savings or investment returns |
| Allocation-distance illustration | Differences under a stated transformation or allocation rule | An implementable portfolio performance claim |
| Rater disagreement | Measurement spread and instability | Accuracy by itself |

The main research contribution remains same-year nowcasting and measurement. The public demonstrations do not make model API calls and do not regenerate the original repeat-measurement archive.
