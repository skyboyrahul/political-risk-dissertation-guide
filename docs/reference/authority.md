# Result authority

A research repository can retain several versions of a result. The authoritative record depends on the dissertation revision and the documented experiment, not simply on the newest filename or the smallest error.

## Preserve the estimand

The mean of fold-level RMSEs differs from an RMSE calculated over all stacked prediction rows. Both can be legitimate summaries, but their values and uncertainty calculations must not be mixed. Country and year dependence, finite-cluster corrections, multiple comparisons and block resampling also affect interpretation.

The current research distinguishes corrected inference from legacy asymptotic or differently resampled output. A historical falsification search is not interchangeable with the later panel-aware rotation design. Refer to the dissertation's exact analysis record when assessing a reported result.

## Read evidence labels literally

| Evidence status | Meaning |
|---|---|
| Exact retained evidence | The specific output and provenance are available in the authorised archive |
| Derived reconstruction | A value was reconstructed with a stated transformation or qualification |
| External input | Evidence depends on a separately supplied source or licence |
| Unresolved | The required lineage or numerical reproduction has not been established |

The public export does not upgrade any of these statuses. Synthetic tests verify selected implementation behaviour and remain separate from empirical evidence. The [ARIMAX audit](arimax.md) provides a concrete unresolved example.
