# Release provenance

This is a fresh public source edition of the research. It has an independent Git history and includes only files selected for public release. The original private repositories remain the research archive.

## Source fidelity

Each code repository records the source snapshot and per-file provenance. Unchanged algorithm files can be checked against their recorded hashes. Public adaptations address data access, embedded observations, private paths, prompt-description text and documentation; they must not silently change an estimator or an evidence qualification.
