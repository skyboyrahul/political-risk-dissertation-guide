The three public repositories provide the complete public reading route. Their source can be browsed directly without a GitHub invitation.

| [political-risk-llm-nowcasting](https://github.com/skyboyrahul/political-risk-llm-nowcasting) | Monthly aggregation, nowcast evaluation, inference and synthetic examples |
| [political-risk-established-baselines](https://github.com/skyboyrahul/political-risk-established-baselines) | Established estimators, feature construction, temporal evaluation and synthetic examples |
| [political-risk-dissertation-guide](https://github.com/skyboyrahul/political-risk-dissertation-guide) | This guide and selected supplementary analysis source |

## What is included

The release contains reviewed source files, schemas and method documentation. Synthetic examples use fictional country names and generated observations that are independent of the research data. The [verification route](reproduce.md) describes what those examples exercise.

## What requires separate access

The empirical research uses licensed ICRG/PRS observations. This release excludes those observations, component-score histories, real prompt anchors, archived model responses, target-bearing results, input archives and private correspondence. It also excludes the complete dissertation source and retained empirical figures.

Exact empirical reproduction requires the relevant data permissions, the original input vintage, archived signals and the matching analysis configuration. Obtaining a current data subscription alone does not recreate the original study snapshot. Consult the author about an authorised review arrangement and the data provider about permitted use. This page does not grant access to or redistribute those data.

The private research archive is maintained separately. Its contents are not part of this website, its search index or these public repositories.
