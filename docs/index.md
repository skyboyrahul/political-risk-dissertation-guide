This public guide accompanies the dissertation's study of monthly LLM readings of Wikipedia for **same-year nowcasting of annual ICRG political-risk ratings**. It connects the methods and qualifications to inspectable source code in three public repositories.

The public editions contain source, method explanations and synthetic examples. The empirical data, archived model responses, observed-target prediction tables and private evidence bundles remain outside this release. Synthetic outputs do not reproduce or validate the dissertation's numerical results.

## Repository terminology

The dissertation uses **established methods**. Where an older reference uses **classical**, including the original name `prs-classical-baselines`, it means those established statistical and machine learning methods. It does not imply that they are old or outdated.

The public code is available for inspection with copyright retained. See [licensing and data access](reviewer-access.md#copyright-and-reuse). No invitation is needed to read this guide or the three public repositories.
