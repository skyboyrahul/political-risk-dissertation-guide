# Public dissertation guide

This repository is a public companion to Rahul Nundlall's Wits dissertation.
Keep the original private research repositories read-only. Never copy their Git
histories, empirical inputs, retained predictions, archives, rendered thesis
figures, credentials, correspondence or licensed scoring descriptions here.

Preserve the scientific distinctions and unresolved limitations. Synthetic
examples demonstrate code execution and do not reproduce the dissertation's
empirical results. Only source explicitly reviewed for public release may enter
research-code/. Publish only dist/ as the website. Do not grant an open-source
licence without the owner's instruction. Commit on a preparation branch, then
promote the verified release to main. Validate the site and public file links
before publication. The original private guide is a separate Site.
